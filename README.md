# AT&T Office Hub

A starter Discord bot for an AT&T Business-to-Business sales office.

## Current commands
- `/ping` — checks that the bot is online.
- `/officehelp` — lists current and planned features.

## Safety
- Never commit `.env` or share your Discord bot token.
- Do not submit customer names, phone numbers, account numbers, addresses, or other customer-identifying information.
- Use only authorized, non-identifying production metrics.
- Competition rewards are intended to be non-monetary (recognition, points, or bragging rights).

## Setup (later step)
1. Install Node.js 22.12 or newer.
2. Download this repository.
3. Run `npm install`.
4. Copy `.env.example` to `.env` and fill in your own values.
5. Run `npm run deploy` to register slash commands.
6. Run `npm start` to start the bot.

Do not put your real `.env` file in GitHub.
